# Project Charter — Budget Buddy CLI

## Миссия

Дать пользователю простой и прозрачный способ вести учёт доходов и расходов из командной строки, без внешних сервисов и с полным контролем над данными.

## Принципы

- **Только stdlib** — никаких внешних зависимостей, запуск из коробки.
- **Локальные данные** — всё хранится в JSON на машине пользователя.
- **Понятность** — документация и сообщения на русском, новичку понятно.
- **Атомарные коммиты** — одна мысль — один коммит.

## Scope (в рамках проекта)

- CLI: добавление, редактирование, удаление, список транзакций.
- Категории доходов/расходов.
- Отчёты: сводка, по категориям, помесячно, экспорт/импорт CSV.
- Лимиты (budget) по категориям.
- QA-скрипты и unit-тесты на stdlib.
- Документация: handbook, spec, примеры.

## Non-scope (не делаем)

- Веб-интерфейс, мобильное приложение.
- Синхронизация с облаком, мультиустройство.
- Внешние API (банки, брокеры).
- Зависимости из PyPI (requests, pandas и т.д.).
