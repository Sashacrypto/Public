# Budget Buddy CLI

Минималистичный CLI-трекер расходов и доходов на Python. Работает "из коробки" без внешних зависимостей — только стандартная библиотека Python.

## Кому полезно

- Тем, кто хочет вести простой учёт финансов без сложных приложений
- Разработчикам, которые предпочитают командную строку
- Новичкам в Python — код использует только stdlib, легко изучать
- Тем, кому важна приватность — данные хранятся локально в JSON

## Быстрый старт

```bash
# Клонируйте репозиторий
git clone https://github.com/Sashacrypto/Public.git
cd Public

# Инициализируйте файл данных
python -m app init

# Добавьте первую транзакцию
python -m app add expense --amount 100 --category "Еда" --note "Обед"

# Посмотрите список
python -m app list

# Получите отчёт
python -m app report summary
```

## Ограничения

- **Только Python stdlib** — никаких внешних зависимостей (requests, pandas и т.д.)
- Данные хранятся в локальном JSON-файле
- Работает на Python 3.7+
